🎉 Dmitry Derepko, Yii3 core team member, just released a tool for generating files with test cases based on class methods signatures.

The name is "Test It!". It could give a very good start if you don't have enough time to write tests (that's when you usually need tests most).

Check it out: [https://github.com/xepozz/test-it](https://github.com/xepozz/test-it)
