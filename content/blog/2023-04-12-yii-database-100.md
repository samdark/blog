First release of [Yii Database and its drivers](https://github.com/yiisoft/db) is done. 

It is a framework-agnostic package to work with different types of databases.  
  
Code looks like Yii2 more or less:


```php
$rows = (new Query($db))  
    ->select(['id', 'email'])  
    ->from('{{%user}}')  
    ->where(['last_name' => 'Smith'])  
    ->limit(10)  
    ->all();
```

📰 Official news: [https://www.yiiframework.com/news/552/yii-database-1-0-0](https://www.yiiframework.com/news/552/yii-database-1-0-0)

I think that should do good for PHP overall because there's not much competition of framework-independent DBALs field.

It will be hard to beat this package though because of years invested into driver edge cases during Yii2 and awesome work done by Wilmer Arambula and Valerii Gorbachev for Yii3.
