My language of choice turned 30!

I've learned PHP 4 at a university to automate software distribution for students. It was easy to write and read (especially compared to Perl), it had an immediate feedback cycle, and it was very easy to deploy. PHP was used for a few other personal projects and then shelved for some time.

I've worked with J2EE. Struts and Spring were a thing these days. The urge to share what I've learned brought me to PHP again. Java was alright for enterprise level projects, but was too clumsy and pricey for a personal blog. When I've tried PHP again, it was 5.1 and then 5.2. It was familiar and unfamiliar at the same time, and it was tempting to use it for something serious. Around 5.3, I've decided to choose it instead of Java for a relatively big system and never looked back.

All these years, PHP was developing and aging quite well:

1. Improving performance, expressiveness, feature set, stability slightly almost every minor release.
2. "Dying" every 5 years with another "killer" technology on the horizon. It was ColdFusion, [ASP.net](https://ASP.net), Django, Ruby on Rails, Flash, AngularJS, Next.js, Golang, and so on. 
2. Being too silent like it's dead for a year or two and then starting to shine like a phoenix with all the events, buzz, new shiny projects, releases etc.

In recent years, I love the fact that it became very mature with a proper foundation, packages infrastructure, standards, and more. While having all that, it is still the same very friendly community where you're not sent to RTFM immediately when asking anything.

Of course, as a current CTO, I'm not a fanboy. I'm not choosing PHP when it is slightly better to use another tech. I'm using Golang for many infrastructural or heavy parts; I'm using Rust or C via FFI, etc. PHP is still awesome for describing domain logic, working as a glue for all that.

Looking forward to another 30 productive years 🎉
