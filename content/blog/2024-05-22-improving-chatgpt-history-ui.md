ChatGPT became a go-to tool for many tasks. It's not a silver bullet but can do many things better than non-professional humans.

Working with it produces many contexts and history and, like browser tabs, you need to navigate is somehow. Standard UI doesn't provide a way to conveniently do so, but there's an extension that fixes it.

[https://myextension.store/searchable-chatgpt/](https://myextension.store/searchable-chatgpt/)

It adds proper search to web version. Works both in Chromium and Firefox. They have a free version that returns first 3 search results (actually, enough for most cases).
