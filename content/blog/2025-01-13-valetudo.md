A few days ago I've installed Valetudo into my Roborock S7 vacuum robot.

Valetudo is an additional software that works as a proxy. It is emulating proprietary server so robot works without any cloud and is exposing REST API to be used with alternative Android app (which is IMO better than stock) and MQTT to be connected to [HomeAssistant](https://www.home-assistant.io/) for further automation. A good number of robots are supported. In my case I had to tear down the robot, shorten the board etc. With some robots it's way easier.

[https://valetudo.cloud/](https://valetudo.cloud/)
