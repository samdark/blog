For a long time as a working group member I am creating a PHP code style specification that is used in majority of modern PHP code. The aim is to make code easier to read and end most of debates such as "should I add space here" or "should this statement be on a separate line" and spend time on something that really matters.

PER is a rolling document i.e. instead of creating multiple PSRs we are going to tag multiple versions.

Version 1.0.0 was a copy of PSR-12. Next version is about expanding spec to latest PHP features and fixing inconsistencies.
